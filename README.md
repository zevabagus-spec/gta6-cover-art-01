Neon Coast — Cover Studio turns any photo into a GTA-style cover in the browser: five multi-panel layouts, five sunset and neon grades, a bold Anton title with a Pacifico script accent, and one-click export as a 1080 x 1080, 1080 x 1350 or 1920 x 1080 PNG. Everything runs locally and offline — photos are read in the browser and never uploaded, and both fonts are embedded in the app as data URIs.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Load a photo (or a sample), pick a layout and grade, set the title, and export.

To build the submission dossier:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
